# 小米手表 AI 指令助手

`mi-watch-agent-command-pilot` 连接 AI 编程工具与小米穿戴设备，让你在手表上回复提问、处理审批、接收完成提醒。

本仓库已发布协作规范，应用源码与构建工作流待同步。当前已验证机型为 Redmi Watch 5，其他设备的兼容性需分别验证。
