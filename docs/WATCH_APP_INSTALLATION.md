# 指令助手安装与升级

2026-10-02。

- 蓝牙认证成功后自动查询安装状态；手动刷新用于重新检查。
- 使用手表返回的 `version_code` 与内置 `resources/watch-app.json` 的 `versionCode` 比较。当前内置包为 v1.1.6（17）；旧版显示升级提示，新版不会被误报需要升级。
- 手表协议不返回版本名称。只有版本编号与内置包一致时显示对应的 v1.1.6，其他已安装版本显示实际版本编号。
- v1.1.5 将手表图标统一为桌面端的橙色底、白色手表与对勾，使用新的图标资源路径。已有安装需要升级后才会显示新图标。
- v1.1.6 将手表图标的橙色底改为圆形，圆形外透明，保留白色手表和对勾。使用新的 `icon-v5.png` 资源路径，升级后应用列表会采用圆形图标。
- 页面只显示“指令助手”，隐藏通用已安装应用列表。
- 安装、升级、重装均在后端先校验包完整性、检查旧安装；已安装时发送卸载请求，并持续查询直到包消失，再开始新包传输。未安装时直接安装。
- 卸载没有协议确认响应，因此必须检查应用列表；查询失败、蓝牙断开或 30 秒内无法确认移除时停止。重复安装请求被拒绝。
- 安装结果确认后再次核对包名和版本编号；失败后也刷新实际状态。连接重置后忽略旧请求的结果。
- macOS 包包含蓝牙用途说明，避免因缺少 `NSBluetoothAlwaysUsageDescription` 被系统终止。

安装与升级流程的既有验证：前端 23 项测试、Rust 库 34 项测试通过，TypeScript/Vite 构建与 macOS app 打包通过。前端模拟覆盖连接后自动检查、未安装、旧版、新版、检查失败与重试、断开重连后的过期结果，以及安装失败后的状态刷新；后端覆盖卸载顺序、确认失败、超时及重复安装锁。
